# DepthScape

**풍경 사진을 탐색 가능한 2.5D 장면으로.**

DepthScape는 풍경 사진 한 장을 깊이가 있는 레이어 장면으로 변환하는 오픈
소스 프로젝트입니다. 상대 깊이를 추정하고 사진을 전경·중경·배경으로 나눈
뒤, 전경에 가려진 작은 영역을 생성하여 로컬 Python 뷰어에서 제한적인 시차
효과를 보여줍니다.

> [!IMPORTANT]
> DepthScape는 물체 뒤의 실제 모습을 복원하지 않습니다. 가려진 영역은 보이는
> 정보를 바탕으로 AI가 생성하며, 결과에서 생성 콘텐츠임을 명확하게 표시해야
> 합니다. 결과물은 완전하거나 실제 치수가 정확한 3D 복원이 아니라 2.5D 시각
> 경험입니다.

## 목표 경험

```text
풍경 사진
→ 상대 깊이 맵
→ 전경·중경·배경 레이어
→ 가림 및 빈 영역 마스크
→ 배경 이미지와 깊이 보완
→ 레이어 기반 2.5D 장면
→ 제한적인 대화형 시차 뷰
```

첫 번째 뷰어에서는 카메라 이동을 문서화된 작은 범위로 제한합니다. 이를 통해
생성 영역을 줄이고 깊이 경계에서 나타나는 찢어짐을 완화합니다.

## 초기 모델 기준선

- **Depth Anything V2 Small:** 상대 깊이 추정 후보
- **LaMa:** RGB 인페인팅 후보
- **DepthScape 코드:** 레이어 구성, 가림 계산, 깊이 보완, 장면 패키징

정확한 버전, 가중치 라이선스, 하드웨어 요구 사항과 대체 가능성은 재현 가능한
실험으로 검증한 뒤 고정합니다. 기준선에서 중요한 한계가 측정된 경우에만 작은
DepthScape 전용 보정 모델을 검토합니다.

## 범위

첫 번째 릴리스는 다음을 목표로 합니다.

- 로컬 JPG 또는 PNG 풍경 사진 한 장 입력
- 방향과 가로세로 비율 유지
- 상대 깊이와 레이어 마스크 미리보기
- 허용된 카메라 이동에 필요한 배경 영역만 생성
- 관측 픽셀과 생성 픽셀 구분
- 키보드로도 조작 가능한 제한적 시차 뷰
- 결과를 재현할 수 있는 간결한 설정 메타데이터

영상 복원, 실시간 카메라, 자유로운 카메라 이동, 실제 단위 깊이와 완전한 가림
표면 복원은 프로젝트 범위에 포함하지 않습니다.

## 프로젝트 상태

DepthScape는 현재 **기획 및 기준선 평가** 단계입니다. 첫 실험이 진행되는 동안
API, 결과 형식, 모델 선택과 구현 세부 사항이 변경될 수 있습니다.
