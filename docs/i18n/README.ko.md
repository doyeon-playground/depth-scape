# ScenePort

**장면을 공간으로.**

ScenePort는 사진, 영상, 실시간 카메라 입력을 탐색 가능한 3D 환경으로
변환하는 오픈 소스 프로젝트입니다. 단일 사진 프로토타입에서 시작해
다중 시점 영상 복원과 실시간 카메라 기반 공간 캡처로 확장합니다.

> [!IMPORTANT]
> 사진 한 장에는 촬영되지 않은 영역의 정보가 없습니다. 첫 단계에서는
> 완전하거나 실제 치수가 정확한 복원물이 아니라, 깊이를 추정해 만든 3D
> 장면을 제공합니다.

## 비전

ScenePort는 공간 캡처를 더 쉽게 만드는 것을 목표로 합니다.

1. 사진에서 상호작용 가능한 깊이 기반 장면을 만듭니다.
2. 영상 프레임을 이용해 더 완전하고 일관된 형상을 복원합니다.
3. 카메라를 연결해 실시간에 가까운 공간 캡처와 시각화를 구현합니다.

## 첫 번째 MVP: 사진에서 3D로

첫 번째 단계에서는 다음 기능을 구현합니다.

- JPG 또는 PNG 이미지 입력
- 이미지의 깊이 맵 추정
- 이미지의 색상과 깊이를 색상이 있는 3D 형상으로 변환
- 회전, 이동, 확대·축소가 가능한 대화형 뷰어 제공
- 복원 결과의 한계를 사용자에게 명확히 안내

숨겨진 표면의 복원, 실제 단위의 정확한 깊이, 제작용 수준의 형상, 실시간
처리는 첫 번째 단계에서 보장하지 않습니다.

## 프로젝트 상태

ScenePort는 현재 **기획 및 프로토타이핑** 단계입니다. API, 파일 형식,
구현 세부 사항은 예고 없이 변경될 수 있습니다.
