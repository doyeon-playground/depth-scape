# ScenePort

**シーンを空間へ。**

ScenePortは、写真、動画、ライブカメラ映像を探索可能な3D環境へ変換する
オープンソースプロジェクトです。1枚の画像を使ったプロトタイプから始め、
マルチビュー動画による再構成、ライブカメラによる空間キャプチャへと発展
させます。

> [!IMPORTANT]
> 1枚の画像から、撮影されていない領域の形状を知ることはできません。
> 最初のマイルストーンが生成するのは、完全または実寸精度の高い再構成
> ではなく、深度を推定した3Dシーンです。

## ビジョン

1. 写真から操作可能な深度ベースのシーンを生成します。
2. 動画フレームを使い、より完全で一貫した形状を再構成します。
3. カメラを接続し、準リアルタイムの空間キャプチャと可視化を目指します。

## 最初のMVP：写真から3Dへ

- JPGまたはPNG画像を受け付けます。
- 画像から深度マップを推定します。
- 色と推定深度を、色情報を持つ3D形状へ変換します。
- 回転、移動、ズームが可能なインタラクティブビューアーで表示します。
- 再構成の限界を利用者に明示します。

隠れた面の復元、実寸精度、制作向け品質の形状、リアルタイム処理は、
最初のマイルストーンの対象外です。
