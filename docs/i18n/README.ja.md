# DepthScape

**風景写真を探索できる2.5Dシーンへ。**

DepthScapeは、1枚の風景写真を奥行きのあるレイヤーシーンへ変換する
オープンソースプロジェクトです。相対深度を推定し、画像を前景・中景・背景に
分け、前景に隠れた小さな領域を生成して、ブラウザーで制限されたパララックス
表示を提供します。

> [!IMPORTANT]
> DepthScapeは、物体の後ろにある実際の内容を復元するものではありません。
> 隠れた領域は見えている情報からAIが生成するため、生成コンテンツであることを
> 明示する必要があります。結果は完全または実寸精度の高い3D再構成ではなく、
> 2.5Dの視覚体験です。

## 目標とする体験

```text
風景写真
→ 相対深度マップ
→ 前景・中景・背景レイヤー
→ オクルージョンと穴のマスク
→ 背景画像と深度の補完
→ レイヤー型2.5Dシーン
→ 制限付きインタラクティブ・パララックス表示
```

最初のビューアーでは、カメラ移動を文書化された小さな範囲に制限します。
これにより生成領域を抑え、深度境界の破綻を軽減します。

## 初期モデルのベースライン

- **Depth Anything V2 Small:** 相対深度推定の候補
- **LaMa:** RGBインペインティングの候補
- **DepthScapeのコード:** レイヤー構築、可視領域計算、深度補完、シーン生成

正確なバージョン、重みのライセンス、ハードウェア要件、代替候補は、再現可能な
実験で確認してから固定します。重要な限界が測定された場合に限り、小規模な
DepthScape専用補正モデルを検討します。

## 対象範囲

- ローカルのJPGまたはPNG風景写真を1枚受け付けます。
- 向きとアスペクト比を維持します。
- 相対深度とレイヤーマスクを表示します。
- 許可されたカメラ移動に必要な背景領域だけを生成します。
- 観測ピクセルと生成ピクセルを区別します。
- キーボード操作に対応した制限付きパララックス表示を提供します。
- 結果を再現するための簡潔な設定メタデータを保存します。

動画再構成、ライブカメラ、自由なカメラ移動、実寸深度、完全な隠面再構成は
プロジェクトの対象外です。

## プロジェクトの状態

DepthScapeは現在、**企画およびベースライン評価**の段階です。最初の実験中は、
API、成果物形式、モデル選択、実装の詳細が変更される場合があります。
