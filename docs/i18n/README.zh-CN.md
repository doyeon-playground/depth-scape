# ScenePort

**将场景转化为空间。**

ScenePort 是一个开源项目，用于将照片、视频和实时摄像头画面转化为可探索的
3D 环境。项目将从单张图像原型开始，逐步扩展到多视角视频重建和实时摄像头
空间捕获。

> [!IMPORTANT]
> 单张图像无法提供未被拍摄区域的几何信息。第一个里程碑生成的是基于深度
> 推断的 3D 场景，而不是完整或具有精确实际尺寸的重建结果。

## 愿景

1. 从照片生成可交互的深度感知场景。
2. 使用视频帧重建更完整、更一致的几何结构。
3. 连接摄像头，实现接近实时的空间捕获与可视化。

## 第一个 MVP：从照片到 3D

- 接受 JPG 或 PNG 图像。
- 根据图像估计深度图。
- 将图像颜色和估计深度转换为带颜色的 3D 几何结构。
- 在支持旋转、平移和缩放的交互式查看器中显示结果。
- 向用户明确说明重建结果的局限性。

隐藏表面恢复、真实尺度精度、生产级几何质量以及实时处理不属于第一个
里程碑的目标。

## 项目状态

ScenePort 目前处于**规划和原型开发**阶段。API、格式和实现细节可能随时变化。
