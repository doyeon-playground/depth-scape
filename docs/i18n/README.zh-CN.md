# DepthScape

**将风景照片转化为可探索的 2.5D 场景。**

DepthScape 是一个开源项目，用于将一张风景照片转化为具有深度感的分层场景。
它会估计相对深度，将图像分为前景、中景和背景，生成被前景遮挡的小块区域，
并在浏览器中提供受限的视差效果。

> [!IMPORTANT]
> DepthScape 不会还原物体背后的真实内容。被遮挡的区域由 AI 根据可见信息
> 生成，因此必须明确标记为生成内容。结果是一种 2.5D 视觉体验，而不是完整或
> 具有精确实际尺寸的 3D 重建。

## 目标体验

```text
风景照片
→ 相对深度图
→ 前景、中景和背景图层
→ 遮挡与空洞掩码
→ 背景图像与深度补全
→ 分层 2.5D 场景
→ 受限的交互式视差视图
```

第一个查看器会把相机移动限制在有明确说明的小范围内，以减少生成区域并缓解
深度边缘处的撕裂。

## 初始模型基线

- **Depth Anything V2 Small：**相对深度估计候选模型
- **LaMa：**RGB 图像修复候选模型
- **DepthScape 代码：**图层构建、可见性计算、深度补全与场景打包

精确版本、权重许可证、硬件要求和替代方案必须通过可复现的实验验证后才能固定。
只有在测量到重要的基线缺陷后，才考虑训练小型 DepthScape 专用校正模型。

## 范围

- 接受一张本地 JPG 或 PNG 风景照片。
- 保持图像方向和宽高比。
- 预览相对深度和图层掩码。
- 只生成允许的相机移动所需的背景区域。
- 区分观测像素和生成像素。
- 提供支持键盘操作的受限视差视图。
- 保存用于复现结果的精简配置元数据。

视频重建、实时摄像头、自由相机移动、真实尺度深度和完整隐藏表面重建不属于
项目范围。

## 项目状态

DepthScape 目前处于**规划和基线评估**阶段。在第一个实验完成之前，API、
产物格式、模型选择和实现细节都可能发生变化。
